Программы

Исходные файлы проекта не меняются: результат всегда сохраняется отдельной копией. Файлы никуда не отправляются.

Кабельный журнал

CableJournal 0.4.0

Считает длину каждого кабеля из журнала по трассе на плане DWG или DXF и заполняет копию кабельного журнала Excel.

  • Находит кабели на плане по условному обозначению или слою.
  • Предлагает масштаб каждого плана по его заголовку.
  • Добавляет запас, разводку в шкафу и металлорукав по вашим правилам.
  • Спорные строки помечает «Требует уточнения» и не угадывает.

Для DWG нужен AutoCAD 2026. DXF открывается без AutoCAD, Excel не нужен.

Сравнение файлов

FileCompare 0.4.1

Показывает, что добавлено, удалено и изменено между двумя версиями документа. По каждому отличию можно перейти к месту в файле и сохранить отчёт.

  • Excel: значения и формулы, строки сопоставляются по смыслу, а не по номеру.
  • PDF и чертежи: наложение «было — стало», тома на сотни листов.
  • Чертежи AutoCAD и КОМПАС сравниваются по печатным листам.
  • Файлы МЭК 61850 (SCD, ICD, CID) сравниваются по терминалам, сети и подпискам.

Для таблиц нужен Excel, для DWG — AutoCAD 2021 и новее, для своих чертежей — КОМПАС-3D. PDF и МЭК 61850 сравниваются без дополнительных программ.

PDF Bookmark Studio

PDF Bookmark Studio 1.0.0

Создаёт закладки и ссылки в томах PDF. Результат сохраняется рядом с оригиналом как «имя_закладки.pdf».

  • Закладки по листам с названиями из ведомости.
  • Ссылки из ведомости рабочих чертежей и «Содержания тома».
  • Сразу пачка томов: сохраняет те, где нет замечаний.
  • Находит двойную нумерацию листов и расхождения ведомости со штампом.

Дополнительные программы не нужны.

Лаунчер

OKUNEV Engineering Tools 1.1.1

Одно окно для всех программ: запуск, установка и обновления.

  • Показывает, какие программы установлены и в каких версиях.
  • Сообщает о новой версии, скачивает установщик и проверяет, что файл не повреждён.
  • Обновляет сам себя так же, как программы.

Интернет нужен только для установки и обновлений.

Установка

  1. Скачайте лаунчер

    Файл OKUNEV.Engineering.Tools-Setup-x64.exe, 52 МБ.

  2. Запустите установщик

    Лаунчер ставится только для вас, без прав администратора. Ярлык появится в меню «Пуск».

  3. Установите программы

    В лаунчере откройте «Обновления» и нажмите «Установить» у нужной программы.

Вопросы

Windows пишет «Система Windows защитила ваш компьютер»

Установщики пока не подписаны сертификатом, поэтому фильтр SmartScreen их не знает. Если файл скачан с этой страницы, нажмите «Подробнее», затем «Выполнить в любом случае». Защиту Windows не отключайте.

Куда ставятся программы и как их удалить?

В вашу папку %LOCALAPPDATA%\Programs. Удаляются как обычно: «Параметры», затем «Приложения». Настройки программ при удалении сохраняются.

Как обновить программу?

Лаунчер сам проверяет обновления. Нажмите «Обновить», закройте программу, если она открыта, и пройдите шаги установщика. Новая версия ставится поверх старой.

Отправляются ли мои файлы в интернет?

Нет. Программы обрабатывают файлы на вашем компьютере. В интернет обращается только лаунчер: чтобы узнать номера новых версий и скачать установщики.

Программы платные?

Нет, бесплатные. Они проверены на реальных проектах, но не заменяют инженерную проверку результата.
