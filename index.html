Программы

Все программы работают на вашем компьютере. Файлы проекта никуда не отправляются, а исходные файлы не меняются.

КЖ

Кабельный журнал

CableJournal 0.4.0

Считает длину каждого кабеля из журнала по трассе на плане DWG/DXF и заполняет копию кабельного журнала Excel.

  • Сама находит кабели на плане по условному обозначению или слою.
  • Предлагает масштаб каждого плана по его заголовку.
  • Учитывает запас, разводку в шкафу и металлорукав. Значения можно настроить.
  • Спорные строки помечает «Требует уточнения», а не угадывает.

Нужно: для DWG — установленный AutoCAD 2026. Файлы DXF открываются без AutoCAD. Excel не нужен.

Ср

Сравнение файлов

FileCompare 0.4.1

Показывает, что добавлено, удалено и изменено между двумя версиями документа. Можно перейти к каждому отличию и сохранить отчёт.

  • Excel: значения и формулы, строки сопоставляются по смыслу, а не по номеру.
  • PDF и чертежи: наложение «было/стало», тома на сотни листов.
  • Чертежи AutoCAD и КОМПАС сравниваются по печатным листам.
  • Файлы цифровой подстанции МЭК 61850 (SCD, ICD, CID…) сравниваются по смыслу.

Нужно: Excel — для таблиц, AutoCAD 2021+ — для DWG, КОМПАС-3D — для своих чертежей. Для PDF и МЭК 61850 ничего не нужно.

PDF

PDF Bookmark Studio

PDF Bookmark Studio 1.0.0

Создаёт закладки и ссылки в томах PDF. Результат сохраняется рядом с оригиналом как <имя>_закладки.pdf.

  • Закладки по листам с названиями из ведомости.
  • Ссылки из ведомости рабочих чертежей и «Содержания тома».
  • Сразу целая пачка томов: «Сохранить тома без замечаний».
  • Находит ошибки: двойную нумерацию листов, расхождение ведомости и штампа.

Нужно: ничего, кроме Windows.

Лаунчер

OKUNEV Engineering Tools 1.1.1

Одно окно для всех программ: запуск, установка и обновления.

  • Показывает, какие программы установлены и какие версии.
  • Сообщает о новой версии и сам скачивает установщик.
  • Обновляет себя так же, как программы.

Нужно: интернет — для установки и обновлений. Права администратора не нужны.

Как установить

  1. Скачайте лаунчер

    Кнопка «Скачать лаунчер» вверху страницы. Файл называется OKUNEV.Engineering.Tools-Setup-x64.exe.

  2. Запустите установщик

    Лаунчер ставится только для вас, права администратора не нужны. Ярлык появится в меню «Пуск».

  3. Установите программы

    В лаунчере откройте «Обновления» и нажмите «Установить» у нужной программы. Лаунчер скачает её установщик и запустит его.

Вопросы

Windows пишет «Система Windows защитила ваш компьютер»

Установщики пока не подписаны сертификатом, поэтому фильтр SmartScreen их не знает. Если файл скачан с этой страницы, нажмите «Подробнее» → «Выполнить в любом случае». Защиту Windows не отключайте.

Куда устанавливаются программы и как их удалить?

Каждая программа ставится в вашу папку %LOCALAPPDATA%\Programs и удаляется как обычно: «Параметры» → «Приложения». Настройки программ при удалении сохраняются.

Как обновить программу?

Лаунчер сам проверяет обновления и показывает «Доступно обновление». Нажмите «Обновить», закройте программу, если она открыта, и пройдите шаги установщика. Новая версия ставится поверх старой.

Отправляются ли мои файлы в интернет?

Нет. Программы обрабатывают файлы на вашем компьютере. В интернет ходит только лаунчер — чтобы узнать номера новых версий и скачать установщики.

Программы платные?

Нет, программы бесплатные. Они созданы для работы проектировщиков АСУ ТП и подстанций и проверены на реальных проектах. Но они не заменяют инженерную проверку результата.
