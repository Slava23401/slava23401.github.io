# АСУ ТП Академия

**Версия 2.0 · учебные материалы и интерфейс, 30.10.2026.**

Бесплатный интерактивный учебный сайт на русском языке для адаптации начинающего инженера-проектировщика АСУ ТП, ССПИ и телемеханики электрических подстанций.

**Разделы:** профессия и границы ответственности; устройство ПС; ТЗ/ОТР/ПД/РД/ЗД/ПНР; ТС/ТИ/ТУ; протоколы и интерфейсы; ГОСТ и СТО с источниками; 20 вводных уроков с целью, объяснением, примером, упражнением, результатом и критериями проверки; 6 инженерных задач с разбором; тест 24 случайных вопроса из банка 36 с перемешиванием вариантов; словарь; итоговый проект.

**Технически:** обычный HTML + CSS + JavaScript, без фреймворков, внешних сервисов, сборки, cookies аналитики, рекламы, учётных записей и передачи персональных данных. Отметки уроков и последний результат теста сохраняются только в `localStorage` браузера и могут быть очищены пользователем.

## Что изменилось в версии 2.0

- Светлый учебный интерфейс с отдельными разделами и переходами по урокам `#day-1` … `#day-20`.
- Сохранены прежние ссылки на разделы и ключи прогресса версии 1. Прогресс остаётся только в текущем браузере; серверной аттестации нет.
- [Учебная тетрадь](materials/workbook.html) содержит вымышленное ТЗ, три схемы, фрагменты ТЗ/ОТР/ПД/РД с пояснениями, упражнение поиска ошибок и сценарий проверки качества данных.
- В `materials/` предоставлены 10 CSV-шаблонов и примеров: сигналы, кабельный журнал, предварительная спецификация, вопросы, требования, замечания и учебные испытания.
- [Порядок чтения нормативов](materials/norm-reading-guide.md) отделяет проверку реквизитов от чтения требований и подтверждения применимости.
- Сохранены улучшения версии 1.1: банк 36 вопросов, случайный вариант из 24, перемешивание ответов и динамический статус учебного минимума. Пустые/неполные попытки не раскрывают решения. После оценки ввод блокируется до новой попытки. Последний результат сохраняется в `asutp-academy-lastscore-v2`; баллы старого фиксированного теста v1 не учитываются. При новой попытке предыдущий результат явно помечен как предыдущий.
- Экзамен остаётся учебной самопроверкой. Он не является защищённой системой экзаменации: клиентский код и правильные ответы доступны в исходниках сайта.

**Готовность обучения:** это расширенный вводный комплект для работы с наставником. Его учебная эффективность ещё не подтверждена результатами реальной группы. Уроки и примеры не заменяют производственное обучение, проверку документации и установленный допуск.

## Запуск локально

Откройте `index.html` в браузере или обслуживайте папку обычным локальным HTTP-сервером. Сохраните всю структуру файлов, включая `lessons.js` и `materials/`. Интернет не требуется для основных разделов и учебного пакета, но ссылки на нормативы ведут на внешние источники. Надёжность локального сохранения при открытии через `file://` зависит от браузера; HTTP-режим предпочтителен для проверки поведения.

## Публикация

Разместите эту папку в репозитории GitHub Pages, например `asu-tp-academy/` внутри `<username>.github.io`. При публикации из ветки `main`, каталога `/ (root)` адрес будет `https://<username>.github.io/asu-tp-academy/`. Если Pages на репозитории не включён: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → / (root) → Save**.

Внутренние файлы:
- `index.html` — основная страница и учебный текст;
- `styles.css` — адаптивный интерфейс, оформление печати;
- `app.js` — база терминов и стандартов, учебные задания, тест, прогресс;
- `lessons.html` — сохранённый дополнительный конспект 20 занятий на одной странице;
- `lessons.js` — 20 вводных уроков и ссылки на упражнения;
- `materials/` — учебная тетрадь, SVG-схемы, CSV-формы и руководство по чтению нормативов;
- `MENTOR_GUIDE.md` — ТЗ мини-проекта, инструкции наставника, критерии оценивания;
- `example_signals_35kv.csv` — пример логической матрицы сигналов;
- `README.md` — этот документ.

## Важные оговорки

1. Все инженерные примеры вымышлены. Они не являются готовыми решениями для реальной ПС и не могут использоваться без подтверждённых исходных данных.
2. В курсе дано упрощение для обучения. Применение ГОСТ/СТО определяется действующей редакцией, областью применения, обязательными требованиями, договором и технической политикой заказчика. Проверка карточек ГОСТ по открытым источникам выполнена **30 октября 2026 года**. Она не доказывает применимость каждого положения, полный текст всех требований или актуальность всех НПА/СТО. Границы проверки перечислены в `materials/norm-reading-guide.md`. Автоматического обновления нет.
3. Не загружайте в публичный GitHub исходные рабочие схемы ПС, фактические каналы, адреса, пароли, топологию защищённых сетей или документы заказчика, не разрешённые к публикации.
4. Проектирование РЗА и расчёт уставок не входят в учебную программу. Интеграция сигналов РЗА входит.
5. Проверка тестов — учебная, не средство аттестации и не оформляет право самостоятельного проектирования.

## Границы технической проверки

Публикация файлов и отсутствие синтаксических ошибок не равны полной приёмке сайта. Проверяются отдельно навигация, сохранение и сброс прогресса, тест, поиск, CSV, печать, мобильный экран и опубликованный адрес GitHub Pages. Сведения о конкретных выполненных прогонах должны подтверждаться отдельным отчётом; этот README не объявляет headless-, браузерные или нормативные тесты пройденными автоматически.

**Использование:** свободно для внутреннего обучения и некоммерческого ознакомления при сохранении ссылок на нормативные источники. Тексты стандартов не копируются; сайт содержит только описания и ссылки.
