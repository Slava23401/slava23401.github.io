# АСУ ТП Академия

Бесплатный интерактивный учебный сайт на русском языке для адаптации начинающего инженера-проектировщика АСУ ТП, ССПИ и телемеханики электрических подстанций.

**Версия:** 1.1 (30.10.2026).

**Разделы:** профессия и границы ответственности; устройство ПС; ТЗ/ОТР/ПД/РД/ЗД/ПНР; ТС/ТИ/ТУ; протоколы и интерфейсы; ГОСТ и СТО с источниками; 20 подробных ежедневных уроков в `lessons.html` и план на 20 дней; 6 инженерных задач с разбором; тест 24 вопроса из банка 36 вопросов с перемешиванием вариантов; словарь; итоговый проект.

**Технически:** обычный HTML + CSS + JavaScript, без фреймворков, внешних сервисов, сборки, cookies аналитики, рекламы, учётных записей и передачи персональных данных. Отметки уроков и последний результат теста сохраняются только в `localStorage` браузера и могут быть очищены пользователем.

## Запуск локально

Откройте `index.html` в браузере. Интернет не требуется для основных разделов, но ссылки на нормативы ведут на внешние источники.

## Публикация

Разместите эту папку в репозитории GitHub Pages, например `asu-tp-academy/` внутри `<username>.github.io`. При публикации из ветки `main`, каталога `/ (root)` адрес будет `https://<username>.github.io/asu-tp-academy/`. Если Pages на репозитории не включён: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → / (root) → Save**.

Внутренние файлы:
- `index.html` — основная страница и учебный текст;
- `styles.css` — адаптивный интерфейс, оформление печати;
- `lessons.html` — 20 развёрнутых занятий с теорией, примером, заданием, самопроверкой и результатом для наставника;
- `app.js` — база терминов и стандартов, учебные задания, тест, прогресс;
- `MENTOR_GUIDE.md` — ТЗ мини-проекта, инструкции наставника, критерии оценивания;
- `example_signals_35kv.csv` — канонический пример логической матрицы сигналов; таблица на сайте полностью ему соответствует, загрузка прямой ссылкой;
- `README.md` — этот документ.

## Важные оговорки

1. Все инженерные примеры вымышлены. Они не являются готовыми решениями для реальной ПС и не могут использоваться без подтверждённых исходных данных.
2. В курсе дано упрощение для обучения. Применение ГОСТ/СТО определяется действующей редакцией, областью применения, обязательными требованиями, договором и технической политикой заказчика. Каталог проверен по открытым источникам **30 октября 2026 года**, но не обновляется автоматически.
3. Не загружайте в публичный GitHub исходные рабочие схемы ПС, фактические каналы, адреса, пароли, топологию защищённых сетей или документы заказчика, не разрешённые к публикации.
4. Проектирование РЗА и расчёт уставок не входят в учебную программу. Интеграция сигналов РЗА входит.
5. Проверка тестов — учебная, не средство аттестации и не оформляет право самостоятельного проектирования. Пустые/неполные попытки не оцениваются и не раскрывают решения. После проверки формы повторная попытка создаётся заново из 36 вопросов. Доступ к исходному JavaScript означает, что проверка не защищена от умышленного списывания.
6. Отметки 20 дней и прохождение теста — самопроверка. Итоговую готовность к ограниченным работам под руководством подтверждает **наставник** после проверки мини-проекта (рекомендуемый порог 80/100 без критических ошибок).

**Использование:** свободно для внутреннего обучения и некоммерческого ознакомления при сохранении ссылок на нормативные источники. Тексты стандартов не копируются; сайт содержит только описания и ссылки.
